### 示例 4：多平台规格适配

**能力**：一稿适配抖音/小红书/视频号格式

**输入**：

```json
{
  "content": "我们把应用启动时间从 8 秒压到了 0.3 秒，靠的是……",
  "platform": "小红书"
}
```

**输出**：

## 适配后内容

姐妹们！我发现一个能省 3 小时的工具 😭

之前每天光想选题就要 1 小时，现在打开就有 3 个选题 + 现成文案…

👉 链接放评论区了

## 已满足的约束

- [x] 字数 187 字（平台上限 1000 字）
- [x] 话题标签 4 个（要求 ≥3）
- [x] 无违禁词

## 调整说明

原内容偏书面语，改写为口语化表达；补充 emoji 提升可读性；结尾引导至评论区而非直接放外链（避免平台限流）。

**资产位置**：`skills/multi-platform-spec-adapt/`

### 示例 5：AIGC 标识合规

**能力**：生成内容合规自查与标识提示

**输入**：

```json
{
  "text": "全网最低价，包治百病，100% 有效"
}
```

**输出**：

## 扫描结果

**结论**：不通过

## 违规项

| 位置 | 原文 | 问题类型 | 修改建议 |
|------|------|---------|---------|
| 第 1 句 | 全网最低价 | 极限词 | 改为「同价位中较有优势」 |
| 第 1 句 | 包治百病 | 虚假功效 | 删除，改为具体适用场景描述 |
| 第 1 句 | 100% 有效 | 绝对化表述 | 删除，改为「多数用户反馈良好」 |

## 风险等级

**高** — 同时命中三类违规，直接发布可能被平台处罚

## 补充建议

建议补充 AI 生成内容标识；如涉及功效描述，需提供检测报告支撑。
