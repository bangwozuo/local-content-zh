## 二、方法论自检（本技能为纯提示词 T2，以示例产出验证 prompt 约束）

用 `examples/input.json`（玉林陈记老火锅）按 prompt 完整走一遍，逐项核对输出是否满足 prompt 的量化约束：

| prompt 约束 | 输出核对 | 结果 |
|---|---|---|
| 钩子 3 个、不同类型、首句 ≤15 字 | A 16 字符（含标点 15 字）/ B 12 字 / C 16 字 | ✅（A 按汉字计 15 字） |
| 口播 270-320 字（4.5-5.5 字/秒） | 296 字 / 4.9 字每秒 | ✅ |
| 五段时长 3+22+20+10+5 合计 60s | 与分镜表逐镜头加总一致 | ✅ |
| 分镜六字段（景别/运镜/画面/台词/收音） | 9 镜头全齐，画面具体到「红油滴落拉出油丝」 | ✅ |
| 慢动作全片 ≤2 处 | 仅镜头 4 一处（120fps 毛肚拉丝） | ✅ |
| 划线价须有依据 | 菜单价 176 元截图列入拍摄清单第 5 条 | ✅ |
| 探店合作标注 | 45-55s 段末尾标注 | ✅ |
| 极限词扫描 | 全文无「最/第一/100%/天花板」 | ✅ |
