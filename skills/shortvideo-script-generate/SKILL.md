# 短视频脚本生成

把门店素材写成能直接开拍的脚本：每句台词有画面对应，每个镜头有时长预算。

不做的事：不做账号定位、不剪片、不投放、不承诺播放量。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_local_01_sk01` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 探店编导 |
| 能力族 | 内容生成 · 脚本创作 |
| 复杂度 | `M` |
| 阶段 | `P0` |
| 复用度 | ★★★★★（私域复购管家、团购引流设计师复用文案骨架） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

1. **五段式结构**：0-3s 钩子（≤15 字，决定完播）/ 3-25s 场景菜品（B-roll 证据链）/
   25-45s 亮点与价格（人均锚点）/ 45-55s 团购引导（POI + 探店合作标注）/ 55-60s 结尾互动（提问式）
2. **钩子类型库**：价格反差、稀缺排队、提问式、过程展示四类，每次输出 3 个供 A/B 测试
3. **口播字数预算**：4.5-5.5 字/秒，60s 全文 270-320 字，逐段给预算，超了砍中段形容词
4. **六字段分镜表**：景别/运镜/画面内容/台词字幕/收音要点，画面内容具体到"毛肚夹起时的拉丝"
5. **美食镜头黄金参数**：微距特写、靠窗自然光、120fps 慢动作只用于拉丝/浇汁/爆汁

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `store_name` | string | ✅ | 门店名 |
| `category` | string | ✅ | 品类（火锅/烘焙/健身房…） |
| `highlights` | array | ✅ | 真实亮点（招牌菜/工艺/环境，须实地确认） |
| `price_per_head` | number | ✅ | 人均价（不提供则列清单索要，不估算） |
| `deals` | string | ⬜ | 团购套餐与优惠（挂车必填） |
| `duration_s` | number | ⬜ | 目标时长，默认 60 秒 |
| `platform` | string | ⬜ | 投放平台，默认抖音 |

## 输出规格

- `hook_options`：3 个 A/B 钩子（台词 + 类型 + 配套首镜头 + 留人逻辑）
- `script_text`：五段式脚本正文（带时间戳与字数统计）
- `shot_list`：六字段分镜表（时长合计 = 目标时长）
- `shooting_checklist`：拍摄清单（菜品顺序/灯光机位/收音/店家配合项）

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 全部内容作为系统提示词
3. 按上方「输入规格」提供门店信息
4. 得到钩子 A/B 组 + 脚本正文 + 分镜表 + 拍摄清单

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude / ChatGPT** | 新建 Project/GPT → Instructions → 粘贴 `prompt.txt` |

生成后建议把分镜表交给 `voiceover-storyboard-flow` 做时长与语速校验。

## 边界（不做的事）

- ❌ 不虚构排队、翻台率、满座等稀缺性信息
- ❌ 不虚构价格；人均价缺失列清单索要，不估算
- ❌ 不用「最好吃」「天花板」等极限词与违规梗
- ❌ 钩子画面不放门头全景（信息密度最低的镜头劝退观众）
- ❌ 不给"节奏快点""加个转场"这类无法执行的空话
- ❌ 探店合作版本不在 45-55s 标注「探店合作」不放行

## 调用示例

**输入**（`examples/input.json`）：

```json
{
  "store_name": "玉林陈记老火锅",
  "category": "火锅",
  "highlights": ["毛肚每日现撕", "牛油锅底免费续", "人均 65 元"],
  "price_per_head": 65,
  "deals": "抖音团购 88 元双人餐（原价依据：门店菜单价合计 176 元）",
  "duration_s": 60,
  "platform": "抖音"
}
```

**输出**（要点，完整版见 `examples/output.md`）：

- 钩子 A（价格反差）：「人均 65，毛肚管够的老火锅我找到了」
- 钩子 B（过程展示）：慢动作浇牛油 +「这一勺红油，等了 30 分钟」
- 钩子 C（提问式）：「玉林巷子里为什么这口锅天天翻台？」
- 脚本正文五段合计 296 字（4.9 字/秒），分镜 9 个镜头时长合计 60s
