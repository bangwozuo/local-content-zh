# 多平台规格适配

一条素材进，四份平台版出：按四平台规格卡逐平台重排画幅、时长、标题与开头节奏，
不注水、不改事实。

不做的事：不拍片、不剪片、不改事实、不承诺各平台数据。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_local_01_sk04` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 探店编导 |
| 能力族 | 内容改写 · 分发适配 |
| 复杂度 | `M` |
| 阶段 | `P0` |
| 复用度 | ★★★★（私域复购管家、团购引流设计师共用分发链路） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

1. **四平台规格卡**：抖音 9:16 1080×1920 ≤60s / 小红书视频 ≤4min 封面 3:4 标题 ≤20 字 /
   视频号 9:16 或 16:9 / B 站横屏 16:9 2-5min，含各平台调性与挂载方式
2. **时长重排**：60s 竖版 → B 站拆成 2-3min 慢节奏；→ 视频号降语速 4 字/秒换家庭钩子；
   → 小红书 60-90s 另出 ≤1000 字笔记版
3. **标题改写**：每平台 2 个候选——抖音钩子前置 ≤30 字符、小红书搜索词前置 ≤20 字、
   视频号共鸣型 ≤16 字、B 站信息量型 ≤40 字符
4. **事实保真**：价格、菜名、地址、活动条款逐字保留，输出四平台事实核对表
5. **竖转横补偿**：16:9 安全框裁切、字幕上移下三分之一、双机位补拍建议

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `content_text` | string | ✅ | 原素材脚本/口播全文 |
| `source_platform` | string | ✅ | 原平台（默认抖音） |
| `duration_s` | number | ⬜ | 原时长，默认 60 |
| `facts` | array | ✅ | 原素材中的事实清单（价格/菜名/地址/条款），用于保真核对 |
| `targets` | array | ⬜ | 目标平台，默认全四平台 |

## 输出规格

- `matrix`：规格适配矩阵（画幅/时长/标题候选×2/开头改动/封面要求/挂载）
- `scripts_by_platform`：各平台版脚本（抖音版/小红书笔记+视频/视频号版/B 站版）
- `fact_check`：事实核对表（原素材 vs 各平台版逐条打勾）
- `reshoot_list`：需补拍/重剪清单

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 全部内容作为系统提示词
3. 提供原脚本、事实清单与目标平台
4. 得到适配矩阵 + 四平台版脚本 + 事实核对表

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude / ChatGPT** | 新建 Project/GPT → Instructions → 粘贴 `prompt.txt` |

发布前建议交给 `aigc-label-compliance` 做各平台合规复审。

## 边界（不做的事）

- ❌ 不注水凑时长（信息密度 <1 个信息点/20s 即失败）
- ❌ 不改事实：价格、菜名、地址、活动条款逐字保留
- ❌ 不给抖音版加「点赞关注不迷路」类引流话术
- ❌ 不在 B 站版塞抖音式快剪（节奏错配弃片率高）
- ❌ 规格卡数字以平台官方最新公示为准，过期时标注「待核对官方」

## 调用示例

**输入**（`examples/input.json`）：

```json
{
  "content_text": "【0-3s】人均 65，毛肚管够的老火锅我找到了……",
  "source_platform": "抖音",
  "duration_s": 60,
  "facts": ["人均 65 元", "团购 88 元双人餐", "菜单价 176 元", "玉林横街"],
  "targets": ["小红书", "视频号", "B站"]
}
```

**输出**（要点，完整版见 `examples/output.md`）：

- 小红书标题：「成都玉林火锅推荐｜人均65 现撕毛肚」（18 字，含 4 个搜索词）
- 视频号标题：「带爸妈吃玉林 20 年老火锅」（13 字）
- B 站标题：「成都玉林巷子火锅实测：176 元菜单价吃出什么水平」
- 事实核对表 4 条全部一致；补拍清单 2 条（横屏安全框、封面 3:4 补拍）
