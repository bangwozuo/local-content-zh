# 团购挂载文案

把一个团购套餐写成能挂上视频的转化文案——标题、卖点、价格锚点、使用规则四件套，
每一句都经得起平台审核。

不做的事：不设计套餐、不定价、不谈佣金。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_local_01_sk03` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 探店编导 |
| 能力族 | 内容生成 · 合规文案 |
| 复杂度 | `M` |
| 阶段 | `P0` |
| 复用度 | ★★★★（私域复购管家、团购引流设计师共用） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

1. **四件套输出**：挂车标题（≤20 字，人群+价值+数字锚点）/ 卖点 3 条（各 ≤25 字，按
   稀缺→分量→便利的转化权重排序，每条对应可拍画面）/ 价格锚点（菜单价与团购价并列式）/
   使用规则 6 项（有效期、时段、限购、预约、附加费、叠加）
2. **划线价合规**：「菜单价 176 元」须有收银截图且逐项加总可复核；「原价」按 7 天内真实
   成交价口径（价格欺诈禁止规定），无依据直接改写
3. **平台审核红线**：探店合作标注（《互联网广告管理办法》2023-05-01 第 9 条）、不虚构排队、
   餐饮不得宣称功效、AI 素材按《人工智能生成合成内容标识办法》（2025-09-01）标识
4. **驳回风险提示**：逐条指出可能被驳回的写法并给出替换文本

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `store_name` | string | ✅ | 门店名 |
| `deal_name` | string | ✅ | 套餐名与内容（含菜品明细与数量） |
| `price` | number | ✅ | 团购售价 |
| `list_price_basis` | string | ⬜ | 划线价依据（菜单截图/收银系统，须可复核） |
| `highlights` | array | ✅ | 真实卖点 2-4 条（须可拍出画面） |
| `rules` | array | ⬜ | 使用规则（有效期/时段/限购/预约…缺项会提示补齐） |
| `platform` | string | ⬜ | 投放平台，默认抖音团购 |

## 输出规格

- `copy`：四件套文案（标题/卖点/价格表述/使用规则/探店合作标注位）
- `basis_list`：依据清单（每条价格与稀缺表述 → 对应材料 → 状态）
- `risk_notes`：驳回风险提示（原写法 → 风险 → 改法）

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 全部内容作为系统提示词
3. 按上方「输入规格」提供套餐信息
4. 得到四件套文案 + 依据清单 + 驳回风险提示

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude / ChatGPT** | 新建 Project/GPT → Instructions → 粘贴 `prompt.txt` |

挂车前建议把成片文案交给 `aigc-label-compliance` 做发布前复审。

## 边界（不做的事）

- ❌ 不虚构原价、折扣基线、销量（「已售 1000+」无后台数据不得写）
- ❌ 不用极限词与「手慢无」「错过等一年」类虚假紧迫
- ❌ 不为转化率建议隐藏使用规则（限制条件必须前置可见）
- ❌ 不建议刷单、刷好评、雇佣排队等违规拉量手段
- ❌ 套餐信息不全时列清单索要，不编造菜品与价格

## 调用示例

**输入**（`examples/input.json`）：

```json
{
  "store_name": "玉林陈记老火锅",
  "deal_name": "双人火锅套餐（毛肚+鸭血+酥肉+3素菜+牛油锅底+2饮料）",
  "price": 88,
  "list_price_basis": "门店菜单价合计 176 元（菜单截图 #1）",
  "highlights": ["毛肚每日现撕", "牛油锅底免费续", "地铁 3 号线口 100 米"],
  "rules": ["购买后 7 天有效", "周六日可用", "每桌限用 1 份", "免预约"],
  "platform": "抖音团购"
}
```

**输出**（要点，完整版见 `examples/output.md`）：

- 标题：「玉林老火锅双人餐｜88 元 6 菜 1 锅底」（18 字）
- 价格表述：菜单价 ¥176｜团购 ¥88（依据：#1 菜单截图）
- 风险提示：「原价 176」→ 改为「菜单价 176」（无 7 天成交价记录）

## 合规声明

- 本技能输出为 **AI 辅助生成草稿**，上架前须经商家与平台双重人工确认
- 价格表述遵循《广告法》《禁止价格欺诈行为的规定》；以官方最新口径为准
- 按平台要求完成 AI 生成内容标识；对外发布保留人工确认环节
