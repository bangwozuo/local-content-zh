# 使用示例 —— 团购挂载文案

## 示例 1：火锅店双人餐挂抖音团购（完整流程）

**输入**（`examples/input.json`）：玉林陈记老火锅 / 双人套餐（毛肚+鸭血+酥肉+3素菜+锅底+2饮料）/
售价 88 元 / 菜单价 176 元（菜单截图 #1）/ 3 条真实卖点 / 4 条规则。

**输出要点**（完整版见 `examples/output.md`）：

| 件 | 结果 |
|---|---|
| 标题 | 「玉林老火锅双人餐｜88 元 6 菜 1 锅底」18 字 |
| 卖点 | 现撕毛肚（稀缺）→ 6 菜 1 锅底（分量）→ 地铁口免预约（便利），各 ≤25 字且都有对应镜头 |
| 价格 | 菜单价 ¥176｜团购 ¥88，菜单逐项加总 176 可复核 |
| 规则 | 6 项齐全，未写的两项按「无」补齐并提示商家确认 |
| 风险提示 | 拦下「原价 176」「全成都最划算」「手慢无」「已售 1000+」4 处高危写法 |

**讲解**：商家最初想用「原价 176 现在只要 88」，被依据清单拦下——新上团购没有 7 天内
成交记录，「原价」口径不成立，改为「菜单价 ¥176｜团购 ¥88」并列式，转化信息没丢，风险归零。

## 示例 2：划线价无依据的正确处理

**输入**：烘焙店 6 寸蛋糕团购 58 元，用户声称「原价 128」但拿不出任何截图。

**正确行为**：

| 项 | 结果 |
|---|---|
| 价格表述 | 只写「团购 ¥58」，不出现划线价 |
| 风险提示 | 「原价 128」无依据 → 要么提供菜单/收银截图，要么接受无划线价版本 |
| 替代方案 | 把转化压力转到卖点：「动物奶油 6 寸 58 元」用成本词替代折扣感 |

## 示例 3：探店达人挂车（广告标注场景）

**输入**：达人受商家委托探店火锅店并挂车，佣金按核销结算。

**输出要点**：

| 项 | 结果 |
|---|---|
| 标注判定 | 有商业委托 + 挂车 = 互联网广告，文案末行与视频前 3s 均须「探店合作」 |
| 文案差异 | 达人口吻可保留体验感，但「我自己天天来吃」等虚构亲近表述删掉 |
| 依据清单 | 增加合作性质一项：书面合作约定编号 |

## 整改前后对照（上一版 vs 本版）

| 维度 | 上一版 | 本版 |
|---|---|---|
| 结构 | 一段套话文案 | 四件套（标题/卖点/价格/规则）各有字数与排序规则 |
| 价格合规 | 无 | 划线价依据清单 + 「原价」7 天成交价口径 |
| 平台规则 | 一句「遵守广告法」 | 探店合作标注、AI 素材标识、虚假紧迫逐条落地 |
| 风险输出 | 无 | 驳回风险提示（原写法→风险→改法） |
