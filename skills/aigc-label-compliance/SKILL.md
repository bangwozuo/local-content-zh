# AIGC 标识合规

发布前把会招来限流、下架、市监处罚的问题挑出来：AI 标识、广告标注、极限词、
虚构信息四类，给出可执行的整改动作。

不做的事：不重写文案、不评判味道、不代替平台审核下结论。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_local_01_sk05` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 探店编导 |
| 能力族 | 检测判断型 · 合规审查 |
| 复杂度 | `M` |
| 阶段 | `P0` |
| 复用度 | ★★★★★（全部探店工作流的末道闸） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

1. **AI 标识检查**：AI 写稿/AI 配音/AI 生成封面逐项核对平台声明开关与画面内显著标识
   （依据《人工智能生成合成内容标识办法》2025-09-01 施行；元数据标识不可替代显式标识）
2. **广告标注检查**：付费/置换探店 + 挂车 = 互联网广告，须标「广告/探店合作」
   （《互联网广告管理办法》2023-05-01 第 9 条）；置换（免费餐抵劳务）同口径
3. **极限词与虚假信息**：《广告法》第 9 条词表；虚构排队（反不正当竞争法第 8 条）、
   虚构划线价（7 天成交价口径）、食品功效宣称逐条扫描
4. **平台特有风险**：站外导流、未成年人饮酒、引流话术降权
5. **放行标准**：红线 0 且警告 ≤2（均有改法）→ 可进人工终审

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `content_text` | string | ✅ | 待审文案全文（标题+口播+评论区置顶，尽量给全） |
| `platform` | string | ✅ | 抖音/小红书/视频号/B站 |
| `ai_involved` | array | ✅ | AI 成分清单（无/AI写稿/AI配音/AI封面/AI剪辑） |
| `business_type` | string | ✅ | 自费/置换（免费餐）/付费挂车/付费不挂车 |
| `has_deal_link` | boolean | ⬜ | 是否挂团购链接 |

## 输出规格

- `verdict`：AI 成分 / 商业性质 / 三级计数 / 放行判定
- `issues`：问题清单（级别 / 原文片段 / 命中规则 / 依据 / 整改动作）
- `need_material`：需补充材料清单（取号小票、菜单截图等）

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 全部内容作为系统提示词
3. 提供待审文案 + 平台 + AI 成分 + 商业性质
4. 得到分级问题清单与整改动作

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude / ChatGPT** | 新建 Project/GPT → Instructions → 粘贴 `prompt.txt` |

本技能是所有探店工作流的**末道闸**：`storevisit-script-generate-flow`、
`cover-title-generate-flow`、`publish-calendar-review-flow` 的最后一步都过这里。

## 边界（不做的事）

- ❌ 不提供谐音、拼音、拆字等规避审核写法（属违规协助）
- ❌ 不以「大家都这么发」为放行理由
- ❌ 不编造法规条款编号，记不清出处写「待核对」
- ❌ 不代替平台审核下结论（本审查是预审）
- ❌ AI 成分拿不准时不放行，标 🔵 要求补充制作信息

## 调用示例

**输入**（`examples/input.json`）：

```json
{
  "content_text": "这家店人均65是我吃过最好吃的火锅！排队3小时也值，原价176现在88……评论区置顶加微信进粉丝群",
  "platform": "抖音",
  "ai_involved": ["AI写稿", "AI生成封面"],
  "business_type": "付费挂车",
  "has_deal_link": true
}
```

**输出**（要点，完整版见 `examples/output.md`）：

- 红线 6 项：「最好吃」（广告法第 9 条）、「排队 3 小时」无小票（反法第 8 条）、
  「原价 176」无成交价依据、未标「探店合作」、「加微信」站外导流、AI 封面无显著标识
- 放行判定：**打回重改**（红线 6 > 0）

## 所属工作流

- `storevisit-script-generate-flow`（探店脚本生成，末步）
- `cover-title-generate-flow`（封面标题生成，末步）
- `publish-calendar-review-flow`（发布日历与复审，复审步）

## 合规声明

- 本技能输出为 **AI 辅助预审结果**，不构成法律意见，发布前必须经人工复核
- 法规与平台规则以官方最新公示为准
- 最终发布动作保留人工确认环节
