# 本地热点追踪

把同城信息源的噪声，筛成「本周值得拍的 3 条选题」，按 A/B/C 分级给出优先级。

不做的事：不写脚本、不写文案、不代发布。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_local_01_sk02` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 探店编导 |
| 能力族 | 数据采集 · 选题决策 |
| 复杂度 | `M` |
| 阶段 | `P0` |
| 复用度 | ★★★★（选题日历、热点工作流共用） |
| 资产形态 | 纯提示词 + 可选 Python 脚本（无模型调用、无 API Key） |

## 能力描述

1. **五源汇总**：抖音同城热榜 / 小红书本地生活 / 大众点评热门 / 节假日节点日历 / 新店开业信息
2. **三因子加权评分**：热度分（log 归一化）×0.4 + 竞争度反向分 ×0.3 + 匹配度 ×0.3，
   外加 48h 半衰的时效衰减；节点类话题（情人节/国庆/暑期等）豁免衰减
3. **A/B/C 分级**：≥70 追、55-69 观察、<55 放弃；附假阳性拦截（新店炒作、天气突发、僵尸话题）
4. **产物落盘**：Excel 选题榜 + PNG 得分图 + JSON 机器可读结果

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `city` | string | ✅ | 门店所在城市 |
| `category` | string | ✅ | 门店品类（火锅/烘焙/健身房…） |
| `candidates` | array | ✅ | 候选热点清单，每条含 `title` / `source` / `heat_48h`（近48h互动量）/ `same_city_videos`（同城同类视频条数）/ `match`（0-1 匹配度，人工标定）/ `hours_since`（距发布小时数） |
| `window_days` | number | ⬜ | 回看窗口，默认 3 天 |

拿不到实时数据时，把热榜条目手动粘贴进来组成 `candidates` 即可——不编造数据。

## 输出规格

- `summary`：候选条数 / A、B、C 级计数 / 本周建议拍摄 Top3
- `rows`：选题榜（热度分、竞争度分、匹配度分、时效系数、总分、级别、备注）
- 产物：`out/选题评估榜.xlsx`、`out/选题得分.png`、`out/hotspot_track.json`

## 使用步骤

### 方式一：纯提示词（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 把 `prompt.txt` 全部内容粘贴为系统提示词
3. 提供城市、品类与候选热点清单（手动粘贴热榜条目）
4. 得到 A/B/C 分级选题榜与淘汰说明

### 方式二：带脚本（精确计算 + 产出文件）

```bash
python3 <SKILL_DIR>/scripts/hotspot_track.py --input input.json --outdir out
python3 <SKILL_DIR>/scripts/hotspot_track.py --demo        # 无输入也能看效果
```

产物：

| 文件 | 内容 |
|---|---|
| `out/选题评估榜.xlsx` | 选题榜（A 级行标红）/ 汇总 |
| `out/选题得分.png` | Top10 得分横向柱状图 |
| `out/hotspot_track.json` | 机器可读结果 |

**分工**：脚本做加权计算、时效衰减、排序与出表（不漏、不猜）；模型做匹配度标定复核与假阳性排除。**数值以脚本输出为准，不要自己算。**

## 边界（不做的事）

- ❌ 不抓取需要登录/付费接口的数据，不绕过平台反爬
- ❌ 不编造热榜条目或互动量数字
- ❌ 不把全网热点当同城热点（异地爆点不代表本城有搜索需求）
- ❌ 不追踪竞争对手负面舆情（蹭对手翻车流量有法律风险）
- ❌ 评分不能替代人工判断：投放痕迹、店家档期须人工确认

## 调用示例

**输入**（`examples/input.json`，节选）：

```json
{
  "city": "成都",
  "category": "火锅",
  "candidates": [
    {"title": "老板把毛肚免费续到凌晨2点的老店", "source": "小红书本地生活",
     "heat_48h": 88000, "same_city_videos": 8, "match": 0.9, "hours_since": 6}
  ]
}
```

**输出**（脚本实跑，8 条候选 → A 级 2 条）：

| # | 选题 | 总分 | 级别 | 备注 |
|---|---|---|---|---|
| 1 | 老板把毛肚免费续到凌晨2点的老店 | 81.0 | A 追 | 低竞争+高匹配 |
| 2 | 国庆去哪吃？成都火锅节10月1日开幕 | 75.6 | A 追 | 节点类，提前布局 |
| 3 | 七夕火锅店情侣套餐预订火了 | 68.4 | B 观察 | 节点类，提前布局 |
| 5 | 春熙路新开的市井火锅，排队2小时也要吃 | 54.9 | C 放弃 | 同类视频 260 条，红海 |
| 8 | 上个月爆火的旋转火锅现在凉凉了 | 9.2 | C 淘汰 | 超 7 天淘汰 |
