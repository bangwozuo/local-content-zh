## 三、边界与已知限制

| 限制 | 说明 |
|---|---|
| 匹配度依赖人工标定 | 脚本只做加权，match 值 0-1 由人工按品类/客单价/位置判定 |
| 数据采集不在脚本内 | 热榜条目需手动粘贴（脚本不做爬虫，避免反爬与账号风险） |
| 节点豁免靠关键词 | 词表覆盖情人节/国庆/暑期等 11 个常用节点，自建节点需自行加入候选标题 |
| 小样本波动 | 候选 < 5 条时归一化区分度下降，建议每周汇总 ≥ 10 条再跑 |
