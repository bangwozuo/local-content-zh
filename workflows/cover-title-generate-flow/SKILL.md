# 封面标题生成

把脚本钩子变成每平台 2 个可上封面的标题：字数、极限词、搜索词、封面规格四道核对，
规则分排序，人工只做终选。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_local_01_wf04` |
| 类型 | **`composite`（复合技能）** |
| 所属员工 | 探店编导 |
| 阶段 | `P0` |
| 复杂度 | `M` |
| 触发方式 | 手动（脚本定稿后） |
| ROI | 封面标题决定 70% 以上点击；A/B 备选省一轮返工 |
| 资产形态 | 提示词编排 + 可选 Python 编排脚本 |

## 能力描述

1. **钩子候选**：从脚本 3 个 A/B 钩子扩写，每平台 ≥3 条，覆盖四类钩子
2. **规格核对**：字数上限（抖音 ≤30 字符 / 小红书 ≤20 字 / 视频号 ≤16 字 / B 站 ≤40 字符）
   + 封面规格（小红书 3:4、视频号去价格字、B 站横版 3 信息点）
3. **极限词扫描**：《广告法》第 9 条词表，命中即淘汰
4. **规则分排序**：`得分 = 2×搜索词命中 + 数字锚点 + 字数达标 - 5×极限词命中`；
   钩子类型四类归类，无强钩子标注重写
5. **Top2 推荐**：每平台 2 条 A/B 备选 + 封面规格，人工终选

## 步骤链路（DAG）

```mermaid
flowchart LR
    IN["输入：钩子段 + 搜索词表"] --> S1["S1 shortvideo-script-generate"]
    S1 --> S2["S2 multi-platform-spec-adapt"]
    S2 --> S3["S3 aigc-label-compliance"]
    S3 --> S4["S4 打分排序（脚本承担）"]
    S4 --> OUT["输出：Top2/平台 + 封面规格"]
    OUT --> HUMAN["人工终选封面"]
```

## 步骤明细

| # | 步骤 | 技能资产 | 输入 | 输出 | 失败处理 |
|---|------|---------|------|------|---------|
| 1 | 钩子候选 | `shortvideo-script-generate` | 钩子段 + 搜索词表 | 每平台 ≥3 条候选 | 钩子段缺失退回脚本步；候选不足如实标注 |
| 2 | 规格核对 | `multi-platform-spec-adapt` | 候选清单 | 字数/封面规格核对 | 超限给压缩候选；未知平台「待核对官方」 |
| 3 | 极限词扫描 | `aigc-label-compliance` | 全部候选 | 红线淘汰 | 候选全灭退回 S1 重写，不带病放行 |
| 4 | 打分排序 | 本流脚本 | 通过的候选 | 每平台 Top2 | platforms 为空中止；无 ✅ 输出空推荐 + 整改要求 |
| 5 | 人工终选 | （人工） | Top2 | 终选标题 + 封面 | 核对封面与标题一致性 |

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `store_name` | string | ✅ | 门店名 |
| `search_words` | array | ✅ | 搜索词表（城市/商圈/品类/价格词） |
| `platforms` | object | ✅ | 平台 → candidates（标题候选 ≥3 条/平台） |

## 输出规格

| 字段 | 类型 | 说明 |
|------|------|------|
| `rows` | array | 候选打分明细（字数/命中/锚点/钩子类型/得分/判定） |
| `recommends` | array | 每平台 Top2 + 封面规格 |
| `issues` | array | 红线候选与整改方向 |
| 产物 | file | `out/封面标题矩阵.xlsx`、`out/cover_title_flow.json` |

## 错误处理

| 情况 | 处理方式 |
|------|---------|
| platforms 为空 | 中止索要候选 |
| 候选含极限词 | 🔴 淘汰 + 整改方向，不计入推荐 |
| 候选全部被淘汰 | 空推荐 + 退回重写要求 |
| 未知平台 | 规格「待核对官方」，字数按 30 兜底 |

## 使用步骤

### 方式一：纯提示词编排（跨平台）

1. 把 `prompt.txt` 全文粘贴为系统提示词
2. 提供钩子段、搜索词表与平台候选
3. 得到候选打分矩阵 + Top2 推荐
4. 人工终选后出封面

### 方式二：带脚本（端到端产物）

```bash
python3 <WF_DIR>/scripts/run_flow.py --input input.json --outdir out
python3 <WF_DIR>/scripts/run_flow.py --demo
```

| 平台 | 编排方式 |
|------|---------|
| **Coze / 扣子** | 新建工作流 → 三个技能节点 + 代码节点跑打分脚本 |
| **Dify** | 新建 Workflow → LLM 节点链 + 代码节点 |
| **WorkBuddy** | 新建 Skill 按 prompt.txt 步骤串联 |

## 边界（不做的事）

- ❌ 不产出含极限词的标题（用户要求也给替换方案）
- ❌ 不编造搜索词命中，只按提供的词表核对
- ❌ 不给单一推荐，A/B 备选是硬要求
- ❌ 不跳过人工终选直接出图发布
- ❌ 未知平台不硬编规格

## 调用示例

**输入**（`examples/input.json`）：玉林陈记老火锅 / 搜索词 4 个 / 三平台 9 条候选。

**输出**（脚本实跑）：红线 1 条（「玉林最好吃的火锅！」→ 0 分淘汰），
Top2 推荐：小红书「成都玉林火锅推荐｜人均65 现撕毛肚」10 分居首，附各平台封面规格。
