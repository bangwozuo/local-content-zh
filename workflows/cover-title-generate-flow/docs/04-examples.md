# 使用示例 —— 封面标题生成工作流

## 示例 1：火锅店三平台标题矩阵（脚本实跑）

**输入**（`examples/input.json`）：搜索词 4 个（成都/玉林/火锅/人均）、三平台各 3 条候选。

**命令**：`python scripts/run_flow.py --input examples/input.json --outdir out`（退出码 0）

**输出**（实跑值）：

| 平台 | Top1 | 得分 |
|---|---|---|
| 小红书 | 成都玉林火锅推荐｜人均65 现撕毛肚 | 10 |
| 抖音 | 成都玉林火锅探店：现撕毛肚管够 | 7 |
| 视频号 | 带爸妈吃玉林20年老火锅 | 6 |

红线 1 条：「玉林最好吃的火锅！」被极限词淘汰（0 分）。
产物：`封面标题矩阵.xlsx`（候选打分 + 平台推荐两 sheet）/ `cover_title_flow.json`。

**讲解**：「最好吃的火锅」读着最带劲却是全矩阵唯一 0 分——极限词 -5 分且无数字锚点。
打分公式的价值就在把「自我感觉」换成「搜索词 × 信息量 × 合规」三把尺子。

## 示例 2：候选全部被淘汰的正确输出

**输入**：某平台 3 条候选全含极限词（「第一」「独家」「最便宜」）。

**输出要点**：

| 项 | 结果 |
|---|---|
| 该平台推荐 | 空，如实标注「无合规候选」 |
| 问题清单 | 3 条红线 + 各自整改方向（改数字锚点/改搜索词结构） |
| 禁止行为 | 不「矮子里拔将军」放行一条，不自动改写后冒充原候选 |

## 示例 3：视频号调性差异

**输入**：同一条「人均65的现撕毛肚老火锅」投视频号。

**输出要点**：规格核对提示「视频号去价格字（熟人场忌报价）」——标题可用，
封面成图时价格字要移出口播首帧；这验证了 S2 规格步不是单纯查字数。

## 示例 4：未知平台不硬编

**输入**：platforms 里混入「快手」。

**行为**：字数按 30 兜底、封面规格标「待核对官方」、判定照常给出——
不编造快手规则，也不拒算整条工作流。

## 整改前后对照（上一版 vs 本版）

| 维度 | 上一版 | 本版 |
|---|---|---|
| 产出 | 5 条「15 字以内带情绪钩子」的笼统清单 | 每平台 Top2 + 逐条打分明细 + 封面规格 |
| 合规 | 无 | 极限词扫描 + 红线淘汰 |
| 排序 | 无 | 确定性规则分（搜索词×2 + 锚点 + 达标 - 极限词×5） |
| 失败处理 | 无 | 候选全灭空推荐、未知平台待核对、不足如实标注 |
