## 三、边界与已知限制

| 限制 | 说明 |
|---|---|
| 打分是规则分非点击率预测 | 反映搜索词/信息密度/合规，不承诺 CTR |
| 搜索词表由用户提供 | 词表质量决定打分区分度；建议含城市/商圈/品类/价格四类 |
| 钩子归类靠关键词 | 「带爸妈吃」类场景共鸣型不在四类词表，标注后由人工终选裁量 |
| 封面成图不在脚本内 | 3:4 成图、标题字占画面比例由人工终选核对 |
